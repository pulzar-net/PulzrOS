Every board below is a directory in [`boards/`](https://github.com/pulzar-net/PulzrOS/tree/main/boards). This page and each board's page are generated from its `board.conf` when the site is built.

A board marked **CI** has an image on every release. One that **needs device support** has its board file and OpenWrt device support in the repository and no image until that support builds and boots on a unit.
